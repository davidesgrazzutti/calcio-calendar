# 📅 Calcio Calendar

Calcio Calendar è un'app sviluppata con **React Native + Expo** che
mostra i prossimi incontri della **Serie A** in un'interfaccia semplice,
moderna e veloce.\
Funziona su **Android**, **Web** ed è compatibile con **EAS Build**.

## 🚀 Tecnologie utilizzate

-   React Native
-   Expo
-   Axios
-   React Navigation
-   JavaScript / TypeScript
-   EAS Build per Android

## 📥 Installazione

Clona la repository:

``` bash
git clone https://github.com/tuo-username/calcio-calendar.git
cd calcio-calendar
```

Installa le dipendenze:

``` bash
npm install
```

## ▶️ Avvio del progetto

Avvio in modalità sviluppo:

``` bash
npm start
```

oppure direttamente via Expo CLI:

``` bash
npx expo start
```

Puoi aprire l'app:

-   su **Android Emulator** premendo `a`
-   su **web** premendo `w`
-   su **app Expo Go** scannerizzando il QR code

## 📱 Build Android (APK / AAB)

### Con EAS Build:

Accedi ad Expo:

``` bash
npx expo login
```

Avvia build Android:

``` bash
eas build -p android
```

## 🌐 Versione Web

Per avviare il progetto in modalità web:

``` bash
npm run web
```
